# Удаление сессии

Плагин добавляет в меню сессии действие удаления — с подтверждением, чтобы
случайно не потерять работу.

## Как это выглядит

1. Откройте меню сессии в левой панели (три точки рядом с названием).
2. Выберите **«Удалить сессию»**.
3. Появится предупреждение: сколько связанных сессий затронуто и что именно
   будет удалено.
4. Введите слово `delete`, чтобы подтвердить. После этого сессия исчезает из
   списка и с диска.

## Связь с синхронизацией

Если установлен плагин «Синхронизация сессий», удаление уезжает в резервную
копию в течение нескольких секунд: на других устройствах сессия тоже исчезнет.
Копия при этом не стирается безвозвратно — она остаётся в архиве
`~/.dsh/dsh-sync/deleted/` и её можно вернуть, скопировав папку обратно в
`~/.dsh/sessions/`.

## Что удаляется

- запись сессии в левом списке;
- лог сессии на диске;
- при включённой опции — файлы проекта, созданные этой сессией.

## Безопасность

- без подтверждения словом `delete` ничего не происходит;
- если сессия кем-то ещё используется или к ней привязаны дочерние сессии,
  плагин предупредит об этом до удаления;
- удаление необратимо только для локальной копии; резервные копии остаются.
